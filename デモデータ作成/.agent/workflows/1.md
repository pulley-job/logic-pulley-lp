# Workflow: Demo Data & Dashboard Creation

## Description
テキストまたは音声による指示から、Googleスプレッドシートのデモデータを作成し、Looker Studioで可視化を行う手順。

## Content

### Phase 1: 要件定義と設計
1. ユーザーの入力（テキスト/音声）から、以下の要素を決定する。
    - **データの目的**: 何を解決/分析するためのデータか（例：学生の成績管理、リハビリ効果測定、売上予測）。
    - **ターゲット読者**: 誰が見るレポートか。
    - **必要なカラム**: 分析に必要な5〜10個のカラム（例：日付、ID、氏名、カテゴリA、カテゴリB、数値1、数値2）。
    - **デモデータの規模**: 初期値として100行程度のデータを想定。

### Phase 2: GASによるデータ基盤構築
1. 以下の要件を満たすGoogle Apps Script (GAS) コードを作成する。
    - スプレッドシートを新規作成する。
    - シート名を「Database」とする。
    - 1行目にヘッダーを設定する。
    - 2行目以降に、目的に沿ったランダムなデモデータを生成して挿入する（日付は直近1年、数値は現実的な範囲で乱数生成）。
    - 作成したスプレッドシートのURLをログに出力する。

2. **ブラウザ操作**: [Google Apps Script Home](https://script.google.com/home) を開く。
3. 「新しいプロジェクト」を作成する。
4. エディタに作成したコードを貼り付け、保存し、実行する。
5. 実行ログから「スプレッドシートのURL」を取得して記憶する。

### Phase 3: Looker Studioによる可視化
1. **ブラウザ操作**: [Looker Studio](https://lookerstudio.google.com/navigation/reporting) を開く。
2. 「作成」→「レポート」をクリックする。
3. データの接続先として「Googleスプレッドシート」を選択する。
4. Phase 2で作成したスプレッドシート（「オーナー」または「URL」から検索）を選択し、「追加」をクリックする。
5. 以下の仕様でレポートを編集する。
    - **タイトル**: データの目的に合わせたタイトルを設定。
    - **チャート1（全体概況）**: スコアカード（合計値や平均値）。
    - **チャート2（推移）**: 日付を軸にした時系列折れ線グラフ。
    - **チャート3（内訳）**: カテゴリ別の円グラフまたは棒グラフ。
    - **インタラクション**: 日付範囲コントロールと、主要カテゴリのプルダウンリストを追加。
6. 「表示」モードに切り替え、レポートのURLを取得する。

### Phase 4: 報告と調整
1. ユーザーに対して以下のフォーマットで完了報告を行う。

    ```markdown
    ## 実装完了報告
    
    ### 1. 構築概要
    - **目的**: {データの目的}
    - **ターゲット**: {ターゲット読者}
    - **Looker Studioの狙い**: {何を見せるための設計か}
    
    ### 2. データ構造（スプレッドシート）
    | カラム名 | データ型 | 説明 |
    | :--- | :--- | :--- |
    | {col1} | {type} | {desc} |
    | ... | ... | ... |
    
    ### 3. アクセスURL
    - [📂 スプレッドシートを開く]({Spreadsheet_URL})
    - [📊 Looker Studioレポートを開く]({LookerStudio_URL})
    ```

2. ユーザーから修正指示（例：「もっと項目を増やして」「グラフを別形式に」）があった場合、Phase 2またはPhase 3に戻り、該当箇所のみを修正して再提示する。
