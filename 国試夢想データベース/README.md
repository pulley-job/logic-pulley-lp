# 国試夢想ダイナミック・データベース

理学療法士国家試験対策問題集を迅速に作成・配布できるWebアプリケーション（GASベース）

## 🚀 セットアップ手順

### 1. GASプロジェクトの作成

1. [Google Apps Script](https://script.google.com) にアクセス
2. 「新しいプロジェクト」をクリック
3. プロジェクト名を「国試夢想ダイナミック・データベース」に変更

### 2. ファイルの追加

以下のファイルをGASエディタに追加してください：

| ローカルファイル | GASでの名前 | 種類 |
|-----------------|-------------|------|
| Code.gs | Code | スクリプト (.gs) |
| SheetService.gs | SheetService | スクリプト (.gs) |
| SearchEngine.gs | SearchEngine | スクリプト (.gs) |
| ExportService.gs | ExportService | スクリプト (.gs) |
| ImportService.gs | ImportService | スクリプト (.gs) |
| index.html | index | HTML |
| styles.html | styles | HTML |
| search.html | search | HTML |
| preview.html | preview | HTML |
| export.html | export | HTML |
| import.html | import | HTML |

> **Note**: GASエディタでHTMLファイルを追加するには、左側の「+」→「HTML」を選択

### 3. マスタースプレッドシートの作成

1. 新しいGoogleスプレッドシートを作成
2. シート名を「問題マスター」に変更
3. 以下のヘッダーを1行目に追加：

```
問題ID | 年度 | 回数 | 時間帯 | 問題番号 | 大分類 | 中分類 | 小分類 | 問題文 | 画像URL | 選択肢1 | 選択肢2 | 選択肢3 | 選択肢4 | 選択肢5 | 正解番号 | 解説テキスト | 自作問題フラグ | 難易度 | 登録日時 | 更新日時
```

4. スプレッドシートのURLからIDをコピー
   - URL例: `https://docs.google.com/spreadsheets/d/【このIDをコピー】/edit`

### 4. スプレッドシートIDの設定

1. GASエディタで「プロジェクトの設定」（⚙️アイコン）をクリック
2. 「スクリプト プロパティ」セクションで「プロパティを追加」
3. 以下を入力：
   - プロパティ: `SPREADSHEET_ID`
   - 値: コピーしたスプレッドシートID

### 5. Webアプリとしてデプロイ

1. 「デプロイ」→「新しいデプロイ」をクリック
2. 「種類を選択」で「ウェブアプリ」を選択
3. 設定：
   - 説明: 任意（例: v1.0）
   - 次のユーザーとして実行: 自分
   - アクセスできるユーザー: 自分のみ（または必要に応じて変更）
4. 「デプロイ」をクリック
5. 発行されたURLにアクセス

## 📱 使い方

### 🔍 検索タブ

1. 年度、時間帯、大・中・小分類でフィルタリング
2. キーワード検索も可能
3. 「検索実行」ボタンをクリック
4. 検索結果から問題を選択

### 📄 プレビュータブ

1. 選択した問題の内容を確認
2. 出力タイプ（問題のみ/解答のみ/解答付き）を切り替え

### 📤 エクスポートタブ

1. 出力タイプを選択
   - 📝 問題のみ
   - ✅ 解答のみ
   - 📚 解答付き問題集
2. 出力形式を選択
   - 📄 Googleドキュメント
   - 📕 PDF
   - 📘 Word
3. 「エクスポート実行」をクリック

### 📥 インポートタブ

1. 「インポートテンプレートを作成」をクリック
2. 作成されたスプレッドシートに問題を入力
3. スプレッドシートIDを入力して「インポート実行」

## 🗂️ カテゴリ分類体系

### 大分類
- 実地
- 専門
- 基礎

### 中分類
- 運動器
- 中枢
- 評価
- 内部
- 運動学
- 精神/心理
- その他

### 小分類（例：運動器）
- 脊髄損傷
- 運動療法（概論）
- 末梢神経障害
- 脊椎疾患・熱傷・変形性関節症
- リウマチ
- スポーツ外傷
- 画像評価・整形外科的テスト

## ⚠️ 注意事項

- 画像を問題に紐付ける場合、Google Driveで「リンクを知っている全員」に共有設定が必要です
- エクスポートされたファイルはGoogle Drive内に作成されます
- 大量の問題を一度にエクスポートすると時間がかかる場合があります
