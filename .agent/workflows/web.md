# LPページ作成ワークフロー

このワークフローは、効果的で魅力的なランディングページ（LP）を作成するための手順です。

## 1. 情報収集

クライアントから以下の情報を収集します：

### 基本情報
- 会社名・サービス名
- 事業内容
- ターゲット顧客

### 目的・CTA
- LPの主な目的（問い合わせ、資料請求、購入など）
- 行動喚起（CTA）の内容

### コンテンツ素材
- 強み・特徴・差別化ポイント
- 実績・お客様の声
- 料金プラン（必要に応じて）
- お問い合わせ方法（電話、メール、フォーム、SNS DMなど）

### デザイン要件
- イメージカラー / ブランドカラー
- デザインの雰囲気（モダン、信頼感、親しみやすいなど）
- ロゴ・画像素材

### 外部リンク
- 公式サイト、SNS（YouTube, note, X, Threads, Instagram等）のURL
- 上記から情報を収集して内容を充実させる

## 2. LPの構成設計

以下のセクションを含めて設計：

1. **ヒーローセクション** - キャッチコピー、サブタイトル、CTA
2. **課題提起（Problem）** - ターゲットの悩みを明確化
3. **解決策（Solution/Services）** - 提供サービスの紹介
4. **選ばれる理由（Features/Why Us）** - 差別化ポイント
5. **ご依頼の流れ（Process）** - ステップ形式で説明
6. **プロフィール（Profile/About）** - 人柄・実績を伝える
7. **お問い合わせ（Contact/CTA）** - 明確な次のアクション
8. **フッター** - リンク、SNS、著作権表示

## 3. 開発

### ファイル構成
```
project/
├── index.html    # メインHTMLファイル
├── styles.css    # スタイルシート
├── script.js     # JavaScript（アニメーション等）
└── assets/       # 画像・フォント等（必要に応じて）
```

### デザイン原則
- **ダークモード** または **ライトモード** をベースに
- **グラデーション** と **グローエフェクト** で高級感を演出
- **マイクロアニメーション** で動的な印象を
- **レスポンシブデザイン** でモバイル対応
- **Google Fonts** でモダンな typography

### 技術スタック
- HTML5 + CSS3（Vanilla CSS）
- JavaScript（バニラJS）
- 外部ライブラリは最小限に

## 4. 確認・テスト

// turbo
1. ブラウザでindex.htmlを開いて表示確認
```bash
open /path/to/project/index.html
```

2. 以下を確認：
   - 各セクションの表示
   - レスポンシブ対応（モバイル表示）
   - リンクの動作
   - アニメーションの動作
   - フォント・カラーの反映

## 5. 修正・調整

クライアントからのフィードバックに基づいて修正：
- テキスト内容の変更
- カラー・デザインの調整
- セクションの追加・削除
- CTA の改善

## 6. 納品

- 全ファイルをまとめて納品
- 必要に応じてホスティング設定（GitHub Pages, Vercel, Netlify等）
